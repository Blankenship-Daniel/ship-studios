Invoke the **dbx-160** skill on `$ARGUMENTS`.

`$1` = a bus / stem / loop; optional `$2` = the goal. The UADx dbx 160 Compressor is UA's model of dbx's
**1976 dbx 160 "VU"** — a **feed-forward, true-RMS, hard-knee Blackmer-VCA** comp. Its signature: on drums it
**ADDS punch — it RAISES crest** (the RMS detector pulls down the sustained body while the sharp transients ride
over the top), the opposite of the crest-*dropping* opto [[la-3a]] and the crest-*holding* tube [[fairchild-660]].
Measured on the Watercolors warm drum bus (thr −30, no makeup): **1.5–2:1 slightly LOWERS crest (16.7); 4:1 →
19.6; 10:1 → 21.4; Inf:1 → 22.4** (source 17.9) — the level→punch crossover is between 2:1 and 4:1. There is
**no attack/release** (program-dependent RMS timing; dbx spec ~15 ms/10 dB → ~3 ms/30 dB, too slow to catch a
drum's leading edge → transients punch through). Sculpt with **COMPRESS** (ratio = crest control), **THRESHOLD**
(lower = more GR = more punch; it IS the drive — no input knob), **PULL/SC** (`sc_filter` = a detector high-pass
that INVERTS the character: ON pulls lows off the detector so the bright transients get clamped → **crest
collapses 20.7→14.7 + bassier** = de-harsh/de-pump, NOT punch), **GAIN** (clean makeup, peak-trimmed away in a
preset) and **MIX** (parallel = weight/density, since the wet is already high-crest). It is an exceptionally
**CLEAN VCA — character is dynamic, not harmonic** (1 kHz THD 0.00001 % at 1:1 → 0.043 % at 4:1 → 0.055 % at
∞:1). The tooling gotcha: 8 params all enums — **the ratio `compress` is a STRING enum (`' 4.0:1'`, leading
space; `'Inf:1'`) and `meter`/`sc_filter` are string/bool** the float dict can't set → drive it through the
[[vst-preset]] harness (`presets/vst/apply_vst_preset.py`, presets `dbx160-drum-punch` ★ / `dbx160-bus-glue` /
`dbx160-parallel-punch`). Load the **`uaudio_dbx_160.vst3`** UADx native build (the `/Components/UAD dbx 160.component`
+ `Universal Audio/.../UAD dbx 160.vst3` twins pass through offline); renders headless here — re-verify on new
machines. **dbx 160 = mono** (dual-mono on a stereo bus). It adds level + changes crest → **A/B
loudness-matched**. Punch/leveling stage, NOT a master — hand off to [[master-track]]. Needs `uv sync --extra
vst`. Measure crest / LRA / true-peak + per-band block-crest (broadband crest up but kick low-band crest down =
"tighter kick, more punch") before→after to prove punch-not-just-louder; defer to the skill + `docs/vst/dbx-160.md`.
Don't conflate variants — the plugin is the hard-knee VU (no OverEasy, no negative/INFINITY+). Report settings,
before→after crest/LRA/density + any tonal shift, and the path.
