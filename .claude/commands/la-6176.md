Invoke the **la-6176** skill on `$ARGUMENTS`.

`$1` is the WAV/stem/bus; the rest hints the goal (vocal channel · warm drum glue · LA-2A opto punch · 1176 smash ·
bus glue · tube colour · tighten). The skill drives the **UADx LA-6176 Signature Channel Strip**
(`/Library/Audio/Plug-Ins/VST3/uaudio_la_6176.vst3`) — UA's **Bill Putnam Jr. Signature Edition** of the hardware
**6176** (**610 tube preamp + 1176 FET compressor**) with the plug-in's new trick: a **MODE switch** that makes the
compressor either the **fast 1176** or the **slow, gentle LA-2A**. A whole **preamp + 2-band EQ + two-flavour
compressor** in one pass. It **measures spectrum/tilt/centroid/crest before & after** and A/Bs loudness-matched.

**Governing facts (measured, this rig):** **renders headless via the `uaudio_` build** (UADx native, no iLok) — NOT
the `UAD LA-6176 Channel Strip.component` passthrough twin. **A bare load already compresses** (default Dyn In + 1176
@ ~5 dB GR; crest 14.6→12.3) → bypass dyn/EQ or `master_bypass` for a clean A/B, and loudness-match. **Preamp:**
`Line`/`Hi-Z` are line-level (g0 = 0.24 % THD clean → g+10 = 3.5 %, even-harmonic tube warmth); **`Mic` is a
high-gain mic pre that hits ~40 % THD on a line-level stem** (crest→5) — use Line on stems, Mic only as deliberate
saturation with `input_pad -15` (Mic-stage only) + `input_gain -10`. **EQ = two broad shelves** (LOW 70/100/200, HIGH
4.5k/7k/10k, ±9 ~1:1), **before** the compressor (a boost drives more GR); `cut_filter 75Hz` HPF. **Dynamics
(`dyn_mode`):** **1176** (FET, fast) drops crest with input/ratio, `1176_atk`/`rel` 0=slow→10=fast, **ALL** =
all-buttons crush+distortion, `1176_mix` = parallel (0 dry→10 wet), `1176_sc_filt` = detector HPF; **LA-2A** (opto,
slow, **no time knobs**) on drums **raises** crest (punch-glue), Comp/Limit + `la2a_pk_red`. The inactive mode's
controls go **inert**. **All 26 params are enums** — the string switches + digit-prefixed `1176_*` can't be set via
`apply-vst-chain`'s float dict → use the **[[vst-preset]]** harness (`apply_vst_preset.py`). **Meters own it** (Gemini
hears mono). Needs `uv sync --extra vst`.

Ready examples: `presets/vst/la6176-warm-drum-glue.json` (Line g+5 warmth + parallel 1176 → crest 14.6→12.1,
warm/tight, measured), `la6176-la2a-drum-punch.json` (LA-2A Comp pk6 → crest 14.6→16.1, opto punch), and
`la6176-vocal-strip.json` (Line + 75 Hz cut + 10k air + LA-2A leveling — the classic vocal chain). Full param surface
+ numbers + history: [`docs/vst/la-6176.md`](../../docs/vst/la-6176.md). Pure-DSP / sibling alternatives: FET grab →
`[L] compress-loop`; opto leveling → [[la-3a]]; tube comp → [[fairchild-660]]; preamp+EQ (no comp) → [[helios-type-69]];
saturation → [[vst-saturate]]; EQ → `[L] apply-eq`. Defer to the skill; report the path (Line/Mic+gain, EQ moves),
**which compressor mode** + settings, before→after crest/centroid/tilt deltas, and the preset/`.state` path.
