03the constraints that matter
▢ Headless

The editor is never opened

Only the plugin's DSP needs a process — show_editor() is never called. No display, no audio device, faster than realtime.

◷ Format

VST3 travels, AU doesn't

VST3 runs on macOS/Windows/Linux. Audio Units are macOS-only at the OS level — they pin the whole pipeline (incl. CI) to a Mac.

⛁ State

Save the patch, not the preset

dump_state captures an opaque raw_state blob (VST3 & AU) for a reproducible re-render — robust where .vstpreset/.fxp loading is flaky.

⟂ Scope

Effects only

Instruments are rejected with a clear error. This is an effect-chain insert — MIDI / instrument rendering is a separate concern (DawDreamer territory).

⚠ Determinism

Opt-in island

The one render tool that loads external, non-deterministic binaries. Behind the vst extra; pin plugin versions; a bad plugin can crash the render.

⌧ Licensing

iLok is a landmine

Copy-protected (iLok/PACE) plugins fail in headless/CI containers. Free, machine-licensed plugins (Airwindows) are the safe render-farm choice.

05the call
# discover what's installed (read-only, no `vst` extra needed)
list-vst-plugins(name_contains="comp")

# run a WAV through an ordered effect chain — offline, headless
apply-vst-chain(
  path="projects/track/mix/draft.wav",
  out_path="projects/track/mix/draft_vst.wav",
  plugins=[
    {"plugin_path": "/Library/Audio/Plug-Ins/VST3/Airwindows Consolidated.vst3",
     "parameters": {"input": 0.8, "output": 0.4}},
    {"plugin_path": "…/VST3/SSL Native X-ValveComp v6.vst3", "bypass": true},
  ],
  dump_state=True,   # write opaque .state blobs for a reproducible re-render
)
