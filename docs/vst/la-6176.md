# UADx LA-6176 Signature Channel Strip — field guide: 610 tube preamp + 2-band EQ + switchable 1176/LA-2A, headless

How to drive the **UADx LA-6176 Signature Channel Strip** (`/Library/Audio/Plug-Ins/VST3/uaudio_la_6176.vst3`) —
Universal Audio's **Bill Putnam Jr. Signature Edition** model of the hand-built hardware **6176** channel strip (a
**610 tube/transformer preamp + 1176 FET compressor**), *plus* a feature the hardware never had: a **dynamics MODE
switch** that turns the compressor into either the **fast 1176** or the **slow, gentle LA-2A**. So it's a complete
**preamp + 2-band EQ + two-flavour compressor** in one — the all-in-one console-channel member of
[[vst-channel-strip]], with a real compressor (unlike the EQ-only [[helios-type-69]]). **Part A** is *measured on this
rig* (the real Pedalboard param surface + our isolation/THD/dynamics renders); **Part B** is a *web-research
synthesis, cited*. The skill [[la-6176]] is the measured workflow over this doc.

> **Repo caveat:** Gemini hears ~16 kbps mono — **meters own** loudness/peak/stereo and the tilt/centroid/crest that
> prove a tonal/saturation/compression move. Verify with `[L] measure-spectrum` / `measure-loudness`. A render that
> "sounds" processed but shows a 0.00 delta is a **passthrough** (wrong build loaded).

## TL;DR (the headline, measured)

1. **It renders headless — load the `uaudio_` build.** `uaudio_la_6176.vst3` loads + processes through Pedalboard
   (param-response confirmed). The **`UAD LA-6176 Channel Strip.component`** is the UAD-2/Apollo build that **passes
   through** offline — never load it ([[vst-verify]]). UADx native = **iLok account** (no dongle) for the render.
2. **A bare load is NOT neutral.** The default state is **Dyn In, 1176 @ input 3 / 8:1 / mix 10** + a preamp level,
   so a plain load *already compresses* (default-load crest 14.6 → **12.3**, not 14.6). For a clean reference set
   `dyn_bypass:"Dyn Byp"` + `eq_bypass:"EQ Byp"` (or `master_bypass:true`). This is the **opposite** of Pro-Q (which
   you must flatten) and like a real console channel that's always *doing something*.
3. **Three sections, one pass.** (a) **610 preamp** — `input_select`/`input_gain`/`input_pad`/`cut_filter`/`level`;
   (b) **610 2-band EQ** — `eq_lo_*` + `eq_hi_*` shelves; (c) **dynamics** — `dyn_mode` **1176 / LA2A** is the headline
   switch, each with its own block.
4. **Preamp: Line/Hi-Z are line-level; Mic is a high-gain MIC pre (the footgun + the heavy-colour path).** On a
   1 kHz tone: **Line g0 = 0.24 %** THD (nearly clean) → **Line g+10 = 3.5 %** (H2/even-harmonic = tube/transformer
   warmth, crest 14.2→11.3). **Mic on a line-level signal = ~40 % THD** (crest crushed to ~5) — it's a mic preamp
   expecting −40…−60 dBFS, so feeding it a line stem nukes it. **Use Line/Hi-Z for stems; reach for Mic only when you
   want heavy saturation** (with the −15 pad + `input_gain −10`). **Hi-Z ≡ Line** electrically offline.
5. **EQ = two broad SHELVES, gain ~1:1, symmetric.** LOW shelf, corner `70/100/200` (higher corner reaches up into
   the body); HIGH shelf, corner `4.5k/7k/10k` (lower corner is broader, reaches down into the mids). `±9` set →
   `±~5–6` at the corner / full value beyond it; boost = cut. `cut_filter:"75Hz"` is a separate HPF (crest 14.3→17.4).
6. **Dynamics — the contrast IS the plugin.** **1176** (FET, fast): crest **falls** with input/ratio (14.2 → 11.8 at
   ALL-buttons); `1176_atk`/`1176_rel` map **0 = slow → 10 = fast** (atk10 catches transients → crest 11.0; atk0
   lets them through → 14.8); **ALL** = most crush + a level/aggression jump; `1176_sc_filt` high-passes the *detector*
   (lows stop triggering GR); `1176_mix` = parallel. **LA-2A** (opto, slow, program-dependent): on drums it **RAISES
   crest** (pk3→13.6, pk6→15.2, pk9→**18.2**) — slow attack lets transients through, levels the sustain = punch/glue;
   on sustained sources it clamps hard. `la2a_ratio` Comp/Limit.
7. **All 26 params are enums → drive it with the [[vst-preset]] harness, not `apply-vst-chain`'s float dict.** The
   character/mode switches (`input_select`, `input_pad`, `cut_filter`, `polarity`, `eq_bypass`, `dyn_bypass`,
   `dyn_mode`, `1176_ratio`, `la2a_ratio`, `meter`) are string enums, and the dynamics knobs carry **digit-prefixed**
   names (`1176_atk`…) — both need `setattr`. The EQ freq/gain are numeric enums (technically float-dict-settable on
   grid), but everything that gives it *character* is a string switch. **Meters own it.**

### Signal flow

`input_select`(+impedance) → `input_pad` → 610 preamp (`input_gain` drive, `cut_filter`, `polarity`) → 610 EQ
(`eq_lo`/`eq_hi` shelves, `eq_bypass`) → `level` → dynamics (`dyn_mode` 1176 **or** LA-2A, `dyn_bypass`). **EQ sits
before the compressor and feeds its detector** — *proven*: a `+8.1 dB` low-shelf boost alone raised output `+8.1 dB`,
but the **same boost into an engaged 8:1 comp raised output only +1.16 dB** (the comp ate ~7 dB of it). So an EQ
boost *drives more gain reduction* — commit to it, or make the level back post-comp (`1176_output`/`level`). The
hardware **JOIN/SPLIT** switch (run the two sections together vs separately) is **not exposed** offline — there is
no reorder param, only the independent `eq_bypass` / `dyn_bypass`. The `dyn_mode` switch makes the *other*
compressor's controls **inert** (measured ~1e-6), so each mode's block is self-contained.

`200` = up into the low-mids/body; high band `4.5k` = broadest (reaches down to ~500 Hz), `10k` = airiest. **Gain maps

hinge). **Boost = cut.** These EQ params are numeric enums, so they *can* go through `apply-vst-chain`'s float dict —
but the rest of the strip can't, so use the harness for the whole thing.

### How to drive it headless

Use **[[vst-preset]]**'s `apply_vst_preset.py` (it `setattr`s every param — strings, bools, and the digit-prefixed

byte-stable re-render. **`probe_plugin.py` passes** for this plugin (it has a numeric output knob to push) — but
always re-measure *detail* (a 0.00 delta = the `.component` twin loaded).

# Part B — how the LA-6176 works (web-research synthesis, cited)

## 1. What it is — the hardware 6176 lineage + the plug-in's new trick

- **The hardware 6176** (UA, released 2004) is a hand-built **Tube Channel Strip = the 610 tube preamp + the 1176LN
  FET limiting amplifier** in one 2U rackmount unit — a studio staple on hits by **Coldplay, Adele, and Pharrell**
  (UA's own disclaimer: "use of artist names does not constitute official endorsement"). The LA-6176 plug-in (≈2024,
  the hardware's **20th anniversary**; ~$299 MAP) is the **Bill Putnam Jr. Signature Edition** model of it, in **UADx
  native + UAD-2/Apollo**, Unison-enabled on Apollo for a sound UA bills as "indistinguishable from an all-analogue
  channel strip." [UA / SoS / Production Expert]
- **The plug-in's headline feature** — *not on the hardware* — is a compressor **MODE switch**: choose the **fast,
  punchy 1176LN** FET compression **or** the **slower, gentler LA-2A** opto leveling. UA bills this as **"a feature
  never before found in a UAD plug-in."** So one channel strip gives you UA's two most famous compressors. [UA]
- **The 610** is Bill Putnam Sr.'s **Modular Amplifier** preamp — a 1960s milestone used to record the Beach Boys,
  Ray Charles, Johnny Cash, and later Coldplay and Adele. Tube/transformer "tone" preamp. [UA]
- **The 1176** is the 1967 Urei FET peak limiter — fast attack (microseconds), the famous **4/8/12/20:1** ratios plus
  the **all-buttons-in ("British"/"Brit mode")** trick (all ratio buttons pressed → aggressive, distorted, pumping —
  a drum-room/parallel classic). [UA / 1176 lore]
- **The LA-2A** is the Teletronix electro-optical (T4 opto) **leveling amplifier** — slow, program-dependent,
  "set-and-forget" smooth leveling with two knobs (Peak Reduction + Gain) and a Compress/Limit switch. [UA / LA-2A lore]
- **Formats:** UADx (native, **AAX/AU/VST3**) and UAD-2/Apollo; **Unison-enabled** on Apollo interfaces (matches the
  hardware mic input impedance + gain staging when tracking). [UA / Sweetwater]

## 2. The 610 preamp + 2-band EQ

- **Input:** Mic / Line / Hi-Z select with impedance options (the Unison input-impedance feature on Apollo), a
  **−15 dB pad**, polarity, and a **75 Hz low-cut**. **Gain** (the preamp drive) + **Level** (output fader) gain-stage
  the tube/transformer — pushing Gain into the Mic input is the way to use it as a **colour/distortion** device.
- **EQ:** a **2-band** 610-style program EQ — a **LOW** band (selectable **70/100/200 Hz**) and a **HIGH** band
  (selectable **4.5k/7k/10k**), each **±9 dB** (in 1.5 dB steps). Broad, musical shelving voiced for the 610. (Part A
  measures these as shelves with ~1:1 gain.)

## 3. The dynamics — 1176 vs LA-2A, in one switch

- **1176 mode (FET, fast):** INPUT sets threshold/GR, OUTPUT is makeup, ratios **1:1/4/8/12/20:1 + ALL** (6
  positions — there is **no "BP"/bypass ratio**; bypass is the separate `dyn_bypass`). Attack ≈ **20 µs (fast) →
  800 µs (slow)**, release ≈ **50 ms → 1100 ms** (1176 convention: max = fastest), lineage-inferred. Use it to
  **grab** transients, add bite/aggression, and for the all-buttons drum-smash. (Part A: crest down; attack
  0=slow→10=fast; ALL crushes + jumps level + ~4× the THD.)
- **LA-2A mode (opto, slow):** **Peak Reduction** + **Gain**, a **Comp/Limit** switch, slow program-dependent
  attack/release (no time knobs). Use it to **level** vocals/bass/bus transparently. (Part A: on drums it raises
  crest — the slow opto misses fast transients while leveling sustain.)
- **MIX** is built-in **parallel** (dry/wet) compression; the **Filter** switch high-passes the **detector**
  side-chain so low end doesn't over-trigger GR; **METER** selects Preamp / GR / Out (cosmetic). [UA manual]

## 4. How engineers use it (verify by ear/meter; quantize to the real steps)

| Source | Starting points |
|---|---|
| **Lead vocal** ★ | the classic 6176 chain: Line preamp, 75 Hz cut, HIGH 10k +3 air, LA-2A **Comp** pk ~4–5 for smooth leveling (or 1176 4:1, input ~4, fast-ish attack for an up-front/aggressive vocal). De-ess after if needed ([[de-ess]]). |
| **Bass / DI** | 610 warmth (Line gain for fatness, or Mic+pad for grit), LOW 100 for weight, LA-2A **Comp** for even level, or 1176 4:1 to control peaks. |
| **Drum bus** | parallel **1176** (4:1, slow attack, MIX ~5–7) for punchy glue, or **LA-2A** for smooth opto glue that keeps punch; LOW 100 weight, HIGH 10k air; `sc_filt`/Filter on so the kick doesn't pump. |
| **Room / parallel smash** | **1176 ALL-buttons** + high INPUT, blended via MIX or a parallel bus — aggressive, pumping. |
| **Electric guitar** | Mic-path drive for colour, HIGH 4.5–7k presence, 1176 4:1/8:1 for sustain. |
| **2-bus glue** | gentle **LA-2A Comp** (low Peak Reduction) for transparent leveling, or 1176 4:1 with parallel MIX. |

## 5. Pitfalls / gotchas

1. **Bare load already compresses** — default is Dyn In + 1176. Bypass dynamics/EQ (or `master_bypass`) for a clean A/B.
2. **Mic path is a mic preamp** — line-level into Mic = heavy distortion (Part A: ~40 % THD). Use Line/Hi-Z on stems;
   Mic only as a deliberate saturation effect with the −15 pad.
3. **1176 attack/release are 0=slow→10=fast** (panel reads "Slow … Fast"); slow attack preserves punch, fast tames it.
4. **ALL-buttons jumps level + distorts** — loudness-match the A/B; it's a sound, not a transparent ratio.
5. **LA-2A has no time knobs** — it's program-dependent; "more" = Peak Reduction, not faster.
6. **Stepped values** — EQ freqs/gains and ratios are committed steps; pick the nearest.
7. **Headless control trap (this rig):** the character/mode switches are string enums + the dynamics knobs are
   digit-prefixed → use the **[[vst-preset]]** harness, not `apply-vst-chain`'s float dict; load the **`uaudio_*.vst3`**
   build (the `UAD …` twin passes through offline).
8. **Unison impedance** is an Apollo tracking feature — tone-inert in plain native/VST use.

> **Pure-DSP / sibling equivalents:** tube/transformer colour → `[L] saturate-loop` / [[helios-type-69]] (preamp+EQ,
> no comp); fast FET-style grab → `[L] compress-loop`; slow opto leveling → **[[la-3a]]** (solid-state opto) /
> tube glue → [[fairchild-660]] / VCA bus glue → [[ssl-bus-compressor-2]]; broad musical EQ → [[pultec-eqp-1a]] /
> `[L] apply-eq`; air → [[excite]]. Reach for the LA-6176 when you want a **whole channel in one pass** with the
> **choice of 1176 or LA-2A** character.
